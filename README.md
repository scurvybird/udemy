## Udemy Lesson 5

Variables = information with a value attached to it and stored for later use

Data types
1. String (class:str)= a piece of text
1. Integers (class:int)= whole numbers (no decimals)
1. Floats (class: float)= numbers with a decimal value attached
1. Booleans = true/false values

Concatenating = combining data variables together for a single combined string
Casting = converting a variable from one data type to another
